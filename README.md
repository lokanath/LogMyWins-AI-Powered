# Log my wins

Build a personal wins journal application for business professionals. Users should be able to log a professional achievement with three fields: date, description of the win and business impact. Users should be able to view all their past entries in a clean list. The app should have a simple professional design including a clean layout, neutral colours, and easy to read. No social features, no sharing, no categories in this version.
